# troncade_layout_attactmode
I made this for my custom multi-game arcade cabinet.
Attract-mode is a popular front-end for MAME. 
https://attractmode.org/
https://www.mamedev.org/

Attract-mode is a highly customizable front-end for MAME and other game emulators.
THIS is a simple layout script for attract-mode. It has one neat feature: it's also a jukebox.
The two files here are set up for a vertical screen.
Go to the "horizontal" folder for the horizontal screen setup.
The jukebox option can be turned off in the layout settings.
If you want to use the jukebox option, you need to provide the music files and probably edit the music lists in the layout.nut script.
